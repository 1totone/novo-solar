## Modelo

```markdown
# NNNN. Título

- Data: AAAA-MM-DD
- Status: proposta | aceita | substituída por NNNN

## Contexto
O problema e as restrições.

## Decisão
O que foi decidido.

## Alternativas consideradas
O que mais foi avaliado e por que não.

## Consequências
O que muda, o que fica mais fácil e o que fica mais difícil.
```
