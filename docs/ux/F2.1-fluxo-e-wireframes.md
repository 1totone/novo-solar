## Fluxo básico

Abrir → **1. Local** (cidade com dados ou EPW) → carta aparece → **2. Fachada** (orientação) → transferidor sobre a carta → **3. Proteção** (α, β, γ) → máscara pintada → **4. Dados sobre a carta** → **5. Imprimir ou exportar**. A rosa dos ventos fica numa aba própria.
