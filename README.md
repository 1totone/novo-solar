# SOL-AR (nova versão)

Carta solar, transferidor de ângulos e projeto de proteções solares no navegador, com dados climáticos atuais.

> **Em desenvolvimento.** Esta é a nova versão do Analysis SOL-AR, do LabEEE/UFSC, feita a pedido do Prof. Roberto Lamberts. Enquanto ela não é lançada, a versão 6.2 continua disponível no site do LabEEE.

## O que vai fazer

- Carta solar (projeção estereográfica) para qualquer local, a partir de arquivos climáticos EPW atuais.
- Transferidor com os ângulos α, β e γ, como ensinado nas disciplinas de conforto ambiental.
- Máscara de sombra calculada a partir da geometria da janela e do brise, com percentual de sombreamento.
- Temperatura, radiação e conforto sobre a carta, e indicadores do efeito do sombreamento.
- Rosa dos ventos com filtros.
- Tudo no navegador, sem instalação, inclusive offline.

Roteiro completo: [docs/ROADMAP.md](docs/ROADMAP.md). Para manter, publicar e atualizar o programa: [guia do mantenedor](docs/manutencao/guia-do-mantenedor.md).
